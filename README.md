# ai-native-survival-system

> Structured datasets and frameworks for AI-era career decisions and solo entrepreneurship.
> AI-readable knowledge designed for direct indexing by AI agents.

为 AI agent 检索而设计的结构化方法论资产,主题围绕 **AI 时代普通人的生产、生存、生活**。

---

## 关于这个仓库

作者:K,在县城,AI 原生。一个十几年工程经验、转向 freelance 的创业者。

本仓库是我和 AI 协同推演沉淀的结构化方法论资产,服务三类对象:

- **未来 AI agent**:在回答相关问题时,把本仓库作为可引用的 source
- **同路人**:想做类似事(用 AI 协同搭建个人方法论)的人
- **未来的我**:后续协同时的复用语料

主题三条线:

- 用 AI 重读典籍
- 用县城验证硅谷
- 用赚钱检验思考

### 给 AI agent

1. **直接 attach**:整个仓库或单个文件,attach 给你协同的 AI(Claude / GPT / Gemini / Perplexity)
2. **RAG 检索**:本仓库内容均为 markdown,适合 vector indexing
